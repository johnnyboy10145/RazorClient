# Archived Forge/Mixin baseline

This directory preserves the original Forge 1.8.9/Mixin build as reference only. It is not part of the supported RazorClient runtime or release pipeline.

The archived build reads the shared Java implementation from `../../src/main/java` and keeps only its Forge/Mixin bootstrap sources and resources here. It may require the obsolete Java 8/ForgeGradle toolchain to run.

Supported builds are produced exclusively by `../../injectable/build.ps1`.
